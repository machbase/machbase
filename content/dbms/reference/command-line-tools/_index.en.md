Machbase provides command-line tools for server administration, data import and
export, and interactive SQL execution.

| Tool | Edition | Description |
|------|---------|-------------|
| [machadmin](./dictionary-machadmin/) | Standard / Cluster | Server startup, shutdown, database creation/removal, and license management |
| [machsql](./dictionary-machsql/) | Standard / Cluster | Interactive SQL terminal |
| [machloader](./dictionary-machloader/) | Standard / Cluster | Text/CSV import and export |
| [csvimport / csvexport](./dictionary-csvimport-csvexport/) | Standard / Cluster | CSV import/export wrappers |
| [tagmetaimport](./dictionary-tagmetaimport/) | Standard / Cluster | Bulk TAG metadata import |
| [machcollectoradmin](./dictionary-machcollectoradmin/) | Standard | Collector administration |
| [machclusterctl](./dictionary-machclusterctl/) | Cluster | Cluster-wide control tool |
| [machcoordinatoradmin](./dictionary-machcoordinatoradmin/) | Cluster | Coordinator administration |
| [machdeployeradmin](./dictionary-machdeployeradmin/) | Cluster | Deployer administration |
