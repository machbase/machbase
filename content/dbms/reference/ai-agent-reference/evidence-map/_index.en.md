Select public evidence that matches the claim being made.

| Claim | Preferred evidence |
|-------|--------------------|
| SQL syntax, function, or type | [SQL reference](/dbms/reference/sql/) |
| Edition, table, or SDK support | [Support scope](/dbms/reference/support-scope-constraints/) and [SDK support](/dbms/development-tools-integration/sdk-support-scope/) |
| Configuration key or default | [Configuration reference](/dbms/reference/configuration/) and the deployed configuration file |
| Runtime catalog column | [System catalog](/dbms/reference/log-logs-system-catalog/) |
| CLI option | [Command-line reference](/dbms/reference/command-line-tools/) and deployed `--help` output |
| Error meaning or action | [Error dictionary](/dbms/reference/error-dictionary-codes/) and [Troubleshooting](/dbms/troubleshooting/) |
| Operational procedure | [Operations, configuration, and recovery](/dbms/operations-configuration-recovery/) |

Preserve version and Edition qualifiers, do not turn example output into a guarantee,
and mark claims that are not confirmed by public canonical documentation.
