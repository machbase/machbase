Do not infer Machbase meanings from generic database terminology.

| Term | Canonical reference |
|------|---------------------|
| TAG, LOG, LOOKUP, VOLATILE, TRANSACTION | [Core concepts](/dbms/core-concepts/) and [Table selection](/dbms/data-modeling-table-design/) |
| Append and SQL INSERT | [Integration concepts](/dbms/development-tools-integration/concepts-common/) |
| ROLLUP | [ROLLUP usage](/dbms/tag-rollup-usage/) |
| BASETIME, BASE DISTANCE, SUMMARIZED | [TAG schema](/dbms/tag-table-usage/table-structure-schema/) |
| AUTH KEY | [Authentication and AUTH KEY](/dbms/security-access-control/authentication-auth-key/) |
| Broker and Warehouse | [Edition and Cluster concepts](/dbms/core-concepts/concepts-edition/) |
| Database, owner, and tablespace | [Multi-database operations](/dbms/operations-configuration-recovery/multi-database/) |

Preserve product object names and SQL keywords. Clarify when a generic term differs from
the Machbase object with the same name.
