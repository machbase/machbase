## 데이터 소실 범위

VOLATILE 테이블의 정의와 데이터는 서버가 종료되면 소멸합니다.

| 사건 | 결과 |
|------|------|
| 서버 정상 종료 | 전체 소멸 |
| 서버 장애 종료 또는 전원 차단 | 전체 소멸 |
| 클라이언트 연결 종료 | 유지 |
| 세션 종료 | 유지 |

## 재시작에 대비한 설계

- 원본은 영속 테이블에 보관합니다.
- 테이블 생성과 초기 적재 SQL을 배포 전에 실제 환경에서 검증합니다.
- 초기 적재의 기준 시각과 중복 처리 방식을 명시합니다.
- 캐시가 없거나 비어 있을 때 애플리케이션의 동작을 정의합니다.
- 재구성 완료를 행 수, 최신 시각, 표본 조회로 확인합니다.

서버 제어 명령 자체를 시작 스크립트 예제로 고정하지 않습니다. 설치 방식과 운영 도구에 맞춰
서버가 정상 기동된 뒤 [운영과 데이터 생명주기](/dbms/volatile-table-usage/operations-lifecycle/)의
재생성 절차를 실행합니다.
