## PVO Cache operations

PVO Cache reuses SQL execution plans. It does not cache query result rows.

<a id="tuning-memory-configuration"></a>

## Memory configuration tuning

Plan PVO Cache, Min-Max Cache, process limits, and transient query memory within the available
physical memory budget.
