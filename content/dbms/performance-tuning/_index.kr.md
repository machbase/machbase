성능 문제를 데이터 모델, 입력 경로, 쿼리 실행 계획, 메모리, 스토리지 순서로 진단하고
조정합니다. 설정값을 변경하기 전에 병목 지점과 재현 조건을 확인하고, 변경 전후를 같은
워크로드로 측정합니다.

## 권장 진단 순서

1. 대상 쿼리와 입력 작업의 지연, 처리량, 오류율을 기록합니다.
2. 데이터 특성과 테이블 타입이 일치하는지 확인합니다.
3. `EXPLAIN`, `V$STMT`, `V$SESSION`으로 실행 상태를 확인합니다.
4. 인덱스, 배치 크기, 캐시, 스토리지 설정을 한 항목씩 조정합니다.
5. 같은 데이터와 워크로드로 변경 효과를 다시 측정합니다.
