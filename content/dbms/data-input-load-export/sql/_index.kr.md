Machbase는 표준 SQL INSERT 구문과 함께 대량 입력을 위한 Append API, 파일 직접 로드를 위한 LOAD DATA INFILE을 제공합니다.

## 이 절에서 다루는 내용

- **[INSERT 구문](./insert/)**: 단건·다건·INSERT SELECT 패턴
- **[Append API](./append/)**: SDK 기반 초고속 대량 입력
- **[LOAD DATA INFILE / FAST LOAD](./load-data-infile-fastload/)**: SQL로 서버 측 파일 직접 로드
