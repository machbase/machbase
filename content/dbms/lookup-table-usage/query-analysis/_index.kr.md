## Lookup 데이터 조회

> **8.5 원문 보강 자료**: 이 문서는 기존 8.5 매뉴얼의 내용을 새 장 구조에 맞춰 보존한 것입니다. Machbase 8.6 기준과 표현이 다른 부분은 같은 절의 최신 리뉴얼 문서를 우선합니다.

SQL 문을 사용하여 데이터를 조회하며, 사용 방법은 Volatile 테이블과 동일하다.
