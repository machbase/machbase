TAG 테이블은 센서·IoT 기기의 계측값을 저장하는 시계열 전용 테이블입니다. 태그(센서) 이름을 `PRIMARY KEY`로, 시간 또는 거리 기준 컬럼을 축으로 대량의 시계열 데이터를 효율적으로 저장합니다.
