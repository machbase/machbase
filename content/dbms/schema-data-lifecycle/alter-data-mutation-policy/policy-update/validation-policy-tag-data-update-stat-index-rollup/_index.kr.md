> **계획된 기능**: 이 페이지는 dbms-nfx#3733 구현 완료 후 갱신됩니다. 현재 기술된 내용은 설계 방향을 바탕으로 한 것입니다.

## 배경

TAG 테이블의 시계열 데이터를 UPDATE하면, 이미 계산된 통계(stat), 인덱스(index), 롤업(rollup) 데이터가 실제 값과 불일치할 수 있습니다. 이를 어떻게 처리하느냐가 TAG data UPDATE 구현의 핵심 과제입니다.

## 영향을 받는 내부 구조

### 통계 정보 (stat)
TAG 테이블에 `SUMMARIZED` 컬럼이 있으면 태그별 최솟값·최댓값·평균 등의 통계가 유지됩니다. 값을 UPDATE하면 통계를 재계산해야 합니다.

### 인덱스
TAG 테이블의 데이터 파티션에 구성된 인덱스가 갱신되어야 합니다.

### 롤업 (rollup)
`WITH ROLLUP` 옵션으로 생성된 TAG 테이블은 시간별 집계 데이터(롤업)를 별도로 유지합니다. 원본 값 변경 시 롤업 재계산이 필요합니다.

## 예상 처리 방식

- 소량(단건~소범위) UPDATE 시: 즉시 stat·rollup 재계산
- 대량 UPDATE 시: 비동기 재계산 또는 일괄 처리 방식 적용 가능

## 현재 권장 사항

TAG 데이터 UPDATE 기능이 지원되기 전까지는:

1. **잘못된 데이터 보정**: 수정값을 새 레코드로 추가하고, 쿼리 시 최신 레코드를 우선 사용하는 애플리케이션 로직으로 처리
2. **롤업 재계산 회피**: 가능하면 수집 단계에서 데이터 품질을 보장하여 사후 수정 필요성을 최소화

> 최신 지원 현황은 Machbase 공식 릴리즈 노트를 확인하세요.
