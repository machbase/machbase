## インストール {#installation}

1. Machbase のダウンロードサイトからインストーラーを取得して実行します。
   開始画面で「Next」をクリックします。

![msi1](/dbms-8.5/installation/windows/msi1.png)

2. 図のインストール先選択画面では、 `C:\Machbase-5.1\` が既定のパスです。
   別のディレクトリにインストールする場合は、パスを変更します。
   ディレクトリを選択したら「Next」をクリックします。
    
![msi2](/dbms-8.5/installation/windows/msi2.png)


3. 進行状況が表示されます。インストールが完了すると「Next」が有効になるので、クリックします。
    
![msi3](/dbms-8.5/installation/windows/msi3.png)

4. 完了画面で「Close」をクリックします。
    
![msi4](/dbms-8.5/installation/windows/msi4.png)


## Machbase の起動 {#launch-machbase}

1. インストールが完了すると、デスクトップに Machbase のショートカットが表示されます。
    ダブルクリックして Machbase サーバーを起動します。
       
![machbase_icon](/dbms-8.5/installation/windows/machbase_icon.png)

3. Machbase サーバーを管理するウィンドウが表示されます。
    メニューをクリックして、サーバーと HTTP REST サービスを操作できます。
    
![machbase_winui](/dbms-8.5/installation/windows/machbase_winui.png)
