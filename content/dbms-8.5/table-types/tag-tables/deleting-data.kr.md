## 개요

Machbase는 성능을 유지하도록 설계된 제약 조건 안에서 Tag 데이터를 효율적으로 삭제하는 기능을 제공합니다. 데이터 수명 주기를 효과적으로 관리하려면 이 제약 조건을 이해해야 합니다.

## Tag 데이터 삭제 제약 조건

Machbase에서는 제한된 조건식으로 Tag 데이터를 삭제할 수 있습니다. 태그 이름,
태그 이름과 시간 조건, 전체 태그 대상 시간 조건, `BEFORE`로 삭제하거나
전체 데이터를 삭제할 수 있습니다.

지원하는 삭제 조건:

* 특정 태그 데이터 삭제
* 특정 태그의 특정 시간 이전 데이터 삭제
* 특정 태그의 특정 시간 범위 데이터 삭제
* 특정 시각 또는 시간 범위의 모든 태그 데이터 삭제
* 특정 시간 이전의 모든 태그 삭제
* 모든 데이터 삭제

## DELETE 문 실행

### 특정 태그 데이터 삭제

### 특정 태그의 특정 시간 이전 데이터 삭제

### 특정 시간 이전의 모든 태그 삭제

Machbase 8.0.50 버전부터는 태그 이름을 지정하지 않고 시간 조건만으로 삭제하는 향상된 DELETE 구문을 지원합니다.

#### BEFORE 절 사용 (레거시 구문)

```sql
DELETE FROM TAG BEFORE TO_DATE('Time-string');
```

#### WHERE 절과 시간 조건 사용 (향상된 구문)

> **참고**: 다음 향상된 구문은 Machbase 8.0.50 이상 버전에서 지원합니다.

```sql
-- 정확한 시간의 데이터 삭제
DELETE FROM TAG WHERE time_column = 'time_string';

-- 특정 시간 이전 데이터 삭제
DELETE FROM TAG WHERE time_column < 'time_string';

-- 특정 시간 이전 또는 해당 시간의 데이터 삭제
DELETE FROM TAG WHERE time_column <= 'time_string';

-- 시간 범위 내의 데이터 삭제
DELETE FROM TAG WHERE time_column BETWEEN 'time_string1' AND 'time_string2';
```

## ROLLUP 데이터 삭제

Machbase에서는 Tag 테이블에 연결된 롤업 데이터도 삭제할 수 있습니다.

### BEFORE 절 사용 (레거시 구문)

```sql
-- 특정 시간 이전의 모든 롤업 데이터 삭제
DELETE FROM TAG ROLLUP BEFORE TO_DATE('Time-string');

-- 모든 롤업 데이터 삭제
DELETE FROM TAG ROLLUP;
```

`BEFORE`에 시간을 지정하면 그 시간 이전의 모든 롤업 데이터가 삭제됩니다. 시간을 지정하지 않으면 모든 롤업 데이터가 삭제됩니다.

### WHERE 절과 시간 조건 사용 (향상된 구문)

> **참고**: 다음 향상된 구문은 Machbase 8.0.50 이상 버전에서 지원합니다.

```sql
-- 정확한 시간의 롤업 데이터 삭제
DELETE FROM TAG ROLLUP WHERE time_column = 'time_string';

-- 특정 시간 이전 롤업 데이터 삭제
DELETE FROM TAG ROLLUP WHERE time_column < 'time_string';

-- 특정 시간 이전 또는 해당 시간의 롤업 데이터 삭제
DELETE FROM TAG ROLLUP WHERE time_column <= 'time_string';

-- 시간 범위 내의 롤업 데이터 삭제
DELETE FROM TAG ROLLUP WHERE time_column BETWEEN 'time_string1' AND 'time_string2';
```

**예제:**

아래 삭제 건수는 롤업 데이터에 따라 달라지는 출력 예시입니다.

```sql
-- 2018-01-15 이전의 롤업 데이터 삭제
Mach> delete from tag rollup where time < '2018-01-15';
14 row(s) deleted.

-- 특정 시간의 롤업 데이터 삭제
Mach> delete from tag rollup where time = '2018-01-15 00:00:00';
1 row(s) deleted.

-- 시간 범위 내의 롤업 데이터 삭제
Mach> delete from tag rollup where time between '2018-01-10' and '2018-01-20';
10 row(s) deleted.
```
