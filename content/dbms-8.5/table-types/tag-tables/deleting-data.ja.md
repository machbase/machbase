## 概要 {#overview}

Tag データの削除には、性能を維持するための制約があります。制約を理解し、データのライフサイクルを管理してください。

## 削除の制約 {#tag-data-deletion-constraints}

制限された条件で削除できます。タグ名、タグ名と時刻、
全タグを対象とした時刻条件、`BEFORE`、または
全行削除を使用できます。

対応する条件：

* 特定タグの全データ
* 特定タグの指定時刻より前のデータ
* 特定タグの指定期間のデータ
* 全タグの指定時刻または期間のデータ
* 全タグの指定時刻より前のデータ
* すべてのデータ

## DELETE の実行 {#execute-the-delete-statement}

### 特定タグの全データを削除 {#delete-specific-tag-data}

### 全タグの指定時刻より前を削除 {#delete-all-tags-before-a-specific-time}

8.0.50 以降では、タグ名を指定せずに時刻条件で削除する拡張構文をサポートします。

#### `BEFORE` 句（従来の構文） {#using-before-clause-legacy-syntax}

```sql
DELETE FROM TAG BEFORE TO_DATE('Time-string');
```

#### 時刻条件付き WHERE 句（拡張構文） {#using-where-clause-with-time-conditions-enhanced-syntax}

> **注意**：以下の拡張構文は Machbase 8.0.50 以降でサポートされます。

```sql
-- 指定時刻のデータを削除
DELETE FROM TAG WHERE time_column = 'time_string';

-- 指定時刻より前を削除
DELETE FROM TAG WHERE time_column < 'time_string';

-- 指定時刻以前を削除
DELETE FROM TAG WHERE time_column <= 'time_string';

-- 指定時刻範囲を削除
DELETE FROM TAG WHERE time_column BETWEEN 'time_string1' AND 'time_string2';
```

## ROLLUP データの削除 {#delete-rollup-data}

Tag テーブルに関連するロールアップデータも削除できます。

### `BEFORE` 句（従来の構文） {#using-before-clause-legacy-syntax-1}

```sql
-- 指定時刻より前の全ロールアップを削除
DELETE FROM TAG ROLLUP BEFORE TO_DATE('Time-string');

-- 全ロールアップデータを削除
DELETE FROM TAG ROLLUP;
```

`BEFORE` に指定した時刻より前の全ロールアップデータを削除します。時刻を省略すると、全データを削除します。

### 時刻条件付き WHERE 句（拡張構文） {#using-where-clause-with-time-conditions-enhanced-syntax-1}

> **注意**：以下の拡張構文は Machbase 8.0.50 以降でサポートされます。

```sql
-- 指定時刻のロールアップを削除
DELETE FROM TAG ROLLUP WHERE time_column = 'time_string';

-- 指定時刻より前のロールアップを削除
DELETE FROM TAG ROLLUP WHERE time_column < 'time_string';

-- 指定時刻以前のロールアップを削除
DELETE FROM TAG ROLLUP WHERE time_column <= 'time_string';

-- 指定期間のロールアップを削除
DELETE FROM TAG ROLLUP WHERE time_column BETWEEN 'time_string1' AND 'time_string2';
```

**例：**

以下の削除件数は、ロールアップデータの内容によって変わる出力例です。

```sql
-- 2018-01-15 より前のロールアップを削除
Mach> delete from tag rollup where time < '2018-01-15';
14 row(s) deleted.

-- 指定時刻のロールアップを削除
Mach> delete from tag rollup where time = '2018-01-15 00:00:00';
1 row(s) deleted.

-- 指定期間のロールアップを削除
Mach> delete from tag rollup where time between '2018-01-10' and '2018-01-20';
10 row(s) deleted.
```
