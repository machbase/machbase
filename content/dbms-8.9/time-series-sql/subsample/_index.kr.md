차트나 탐색에 필요한 관측을 선택해 출력 행 수를 줄입니다. SAMPLE BY의 구간 집계·FILL의 보간과 달리 원래 관측의 시각과 값을 유지합니다.

[공통 실습 준비](../#실습-준비)의 TS13_SUB는 1초 간격 8행입니다.

| ID / 지난 초 | V |
| --- | --- |
| 0 | 0 |
| 1 | 4 |
| 2 | 2 |
| 3 | 7 |
| 4 | -1 |
| 5 | 5 |
| 6 | 1 |
| 7 | 3 |


| 절 | 목적 |
|---|---|
| [13.4.1 LTTB: 곡선의 굴곡 보존](./lttb/) | 이전 선택점·현재 후보·다음 구간 평균점의 삼각형 면적으로 굴곡을 선택합니다 |
| [13.4.2 MINMAX: 구간별 극값 보존](./minmax/) | 시간 범위를 나누고 구간별 최솟값·최댓값 행을 선택합니다 |
| [13.4.3 M4: 시작·종료와 극값 보존](./m4/) | 각 시간 구간의 첫 행·마지막 행·최솟값·최댓값을 선택하고 같은 행은 한 번만 남깁니다 |
| [13.4.4 UNIFORM: 행 위치의 균등 선택](./uniform/) | 값의 크기와 관계없이 행 위치를 고르게 선택합니다 |
| [13.4.5 CADENCE: 일정 행 간격으로 선택](./cadence/) | stride 3은 ID 0·3·6·7을 선택합니다 |
| [13.4.6 SDT: 허용 편차로 관측 압축](./sdt/) | compdev는 값의 단위로 표현한 유한한 0 이상의 허용 편차입니다 |


## 선택과 출력 순서

절 형태는 WHERE·GROUP/SAMPLE/FILL·윈도 계산 뒤, 최종 ORDER BY/LIMIT 전에 적용합니다.
SAMPLE 뒤의 기준 시각은 완성된 버킷 시각입니다. 선택 시각 컬럼을 SELECT에 직접 포함합니다.
추가 조건으로 선택 여부를 필터링하려면 [윈도 형태](../sampling-advanced/)를 사용합니다.
