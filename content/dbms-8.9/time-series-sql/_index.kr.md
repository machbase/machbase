## 실습 준비

[전체 실습 자료](/assets/dbms-8.9/time-series-sql/samples.zip)를 내려받아 풉니다.
실습용 DB에서 [setup.sql](/assets/dbms-8.9/time-series-sql/setup.sql)을 한 번 실행하면
이 장의 모든 예제 데이터를 준비할 수 있습니다. TS13_ 이름의 테이블을 사용하므로
같은 이름의 기존 객체가 없는 DB에서 진행합니다. 운영 데이터와 분리한 실습 DB를 사용합니다.

```bash
unzip samples.zip -d time-series-sql
cd time-series-sql
machsql -s 127.0.0.1 -u SYS -p MANAGER --timezone +0900 -f setup.sql
machsql -s 127.0.0.1 -u SYS -p MANAGER --timezone +0900 -f joins/asof/01.sql
```

서버 포트가 기본값과 다르면 `-P`로 지정합니다. 기본 인증정보와 다르면 -u·-p로 해당 실습 계정을 지정합니다.
개별 예제는 공통 setup 이후 독립적으로 실행할 수 있습니다.
[정상 예제 전체 SQL](/assets/dbms-8.9/time-series-sql/all-normal.sql)은 준비·정상 조회·정리를
순서대로 수행하므로 이미 setup을 실행한 DB에 중복 실행하지 않습니다.
오류 예제는 각 페이지에서 따로 실행합니다.

실습 후 [cleanup.sql](/assets/dbms-8.9/time-series-sql/cleanup.sql)을 실행하면
이 장에서 만든 테이블을 제거합니다. 자동 검증은 자료의 README와 verify_samples.py를 참고합니다.

## 시각과 결과표

공통 기준은 **2027-01-01 00:00:00 +09:00**, 절대 나노초는
`1798729200000000000`입니다. 입력은 FROM_TIMESTAMP로 지정하여 날짜 문자열 해석 차이를 피합니다.
EVENT_S·MOTOR_S·S 등은 이 기준에서 지난 초입니다. TIME_NS는 원본 절대 나노초입니다.
DATETIME 표시 형식과 시간대는 클라이언트·세션 설정에 따라 달라질 수 있으며 절대 시각 비교에는
TO_TIMESTAMP 값을 사용합니다. SAMPLE의 TIME ZONE은 버킷 경계 설정이며 화면 표시 설정과는 다릅니다.

각 예제에는 생략 없는 SQL과 결과표가 있습니다. 큰 결과는 앞부분과 전체 행 수를 표시하고,
전체 결과 JSON을 함께 제공합니다. JSON의 NULL은 SQL NULL, 실수의 마지막 자릿수 차이는
표시 정밀도 차이일 수 있습니다.
