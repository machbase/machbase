Verify user terminology in canonical Machbase documentation instead of assuming general database meanings.

| Term | Canonical Reference |
|------|-------------|
| TAG, LOG, LOOKUP, VOLATILE, TRANSACTION | [Core Concepts](/dbms-8.9/core-concepts/) and [Table Type Selection](/dbms-8.9/data-modeling-table-design/) |
| Append and SQL INSERT | [Common Integration Concepts](/dbms-8.9/development-tools-integration/concepts-common/) |
| ROLLUP | [Using ROLLUP](/dbms-8.9/tag-rollup-usage/) |
| BASETIME, BASE DISTANCE, SUMMARIZED | [TAG Structure and Schema](/dbms-8.9/tag-table-usage/table-structure-schema/) |
| AUTH KEY | [Authentication and AUTH KEY](/dbms-8.9/security-access-control/authentication-auth-key/) |
| Broker, Warehouse | [Edition and Cluster Concepts](/dbms-8.9/core-concepts/concepts-edition/) |
| database, owner, tablespace | [Multiple Database Operations](/dbms-8.9/operations-configuration-recovery/multi-database/) |

Preserve product object names and SQL keywords in responses. If the user's general term differs
from a Machbase object, clarify the distinction first.
