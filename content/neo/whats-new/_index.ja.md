## 2026-10-05 — ショーケースメニューの追加

上部メニューの **Apps** の右側に **ショーケース** リンクが追加されました。
青い背景と小さな再生アイコンで強調されたリンクから、Machbase Neo の活用事例や
デモを簡単に見つけられます。現在のドキュメント言語のショーケースページに移動します。

[ショーケースを見る]({{< relref "/neo/showcases" >}})

## 2026-09-23 — Machbase Neo v8.7.1 リリース

SSH と TQL API に API トークン認証が追加され、シグナル処理とサービス終了の動作が
改善されました。ネストされたファイルシステムのマウントと競合処理、ファイル処理用の
エンドポイント、JSH と Neo-shell のヘルプが改善され、TQL のバッファ制限が修正されました。

[v8.7.1 リリースノート](https://github.com/machbase/neo-server/releases/tag/v8.7.1)
· [すべての変更](https://github.com/machbase/neo-server/compare/v8.7.0...v8.7.1)

## 2026-09-09 — Machbase Neo v8.7.0 リリース

エンジン v8.7 とクライアント v2、複数データベースのサポート、名前付きクエリパラメーターが
導入されました。CSV インポートの性能、SQL の互換性とトランザクション処理、認証と
セッション管理、データベースのバックアップ要求と検証機能が改善されました。

[v8.7.0 リリースノート](https://github.com/machbase/neo-server/releases/tag/v8.7.0)
· [すべての変更](https://github.com/machbase/neo-server/compare/v8.5.10...v8.7.0)
