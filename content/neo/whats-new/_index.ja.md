Machbase Neo の最新ニュースとリリースの主な変更点を、新しい順に紹介します。

## 2026-10-20 — Machbase Neo v8.7.2 リリース

ARRAY データをより便利に探索できるようになり、開始ページを自分専用のワークスペースに
構成する実験的機能が追加されました。チャートやファイル操作の使いやすさが改善され、
認証のデフォルト設定の強化と、サーバー・データベースの安定性向上も反映されています。

- **開始ページのカスタマイズ（実験的機能）**: サーバー起動時に `--experiment true` を
  指定した場合のみ有効になります。ユーザー設定、グループ構成、表示モードに対応しています。
  新規タブのレイアウトや保存、グループ、ダイアログに関する問題も修正されました。
- **ARRAY データの探索**: Data Viewer で数値 ARRAY の要素を選択し、詳細なチャートや表で
  確認できます。選択した要素を Tag Analyzer に送って分析・保存できます。
- **チャートと分析画面の改善**: v5 との互換性を維持した ECharts 6 対応が追加され、
  チャートの実行環境が統合されました。Tag Analyzer の編集内容の消失やポップオーバーの
  動作、ダッシュボードに関する不具合も修正されました。
- **ファイル操作とエラー処理の改善**: ファイルの上書き警告、エンコーディング、
  エラー通知が改善されました。保存ショートカットは macOS では `Cmd+S`、
  その他の環境では `Ctrl+S` で動作します。深くネストされた JSON は画面エラーを
  起こす代わりにテキストで表示し、画面の一部のエラーがアプリ全体に影響しないよう
  エラー処理を強化しました。
- **認証とサーバーの安定性強化**: JWT 署名キーを安全に生成・保存するよう改善しました。
  TQL リクエストの並行実行とキャンセル処理、シェル実行時の出力とエラー処理、
  サーバー運用メトリクスへの並行アクセスと一括保存の安定性も改善されました。
- **データベースエンジンの改善**: DBMS 8.7.2 で旧バージョンのサーバーに対する
  `SQLColumns` の互換性を修正し、一部のクエリの CPU コストを削減しました。
  ARM64 環境のビットマップインデックスのメモリ可視性の問題も修正されました。

**アップグレード時の確認事項:** HTTP・MQTT のトークン認証がデフォルトで有効になります。
これまでトークンなしで HTTP API や MQTT を使用していた場合は、アップグレード前に
クライアントの認証設定を確認してください。コマンドラインオプションで認証を無効にするには、
`--http-enable-token-auth false` と `--mqtt-enable-token-auth false` を明示的に指定します。

## 2026-09-23 — Machbase Neo v8.7.1 リリース

SSH と TQL API に API トークン認証が追加され、シグナル処理とサービス終了の動作が
改善されました。ネストされたファイルシステムのマウントと競合処理、ファイル処理用の
エンドポイント、JSH と Neo-shell のヘルプが改善され、TQL のバッファ制限が修正されました。

## 2026-09-09 — Machbase Neo v8.7.0 リリース
