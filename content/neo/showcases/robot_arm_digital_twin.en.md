Store robot-arm motion and sensor data as time series, then analyze it in a dashboard with this Machbase Neo Physical AI demo.

{{< icon "github" >}} https://github.com/machbase/neo-pkg-robot-demo

{{< youtube JeABxt2JYFI >}}

This Physical AI demo is based on the DROID robot dataset.

**Highlights**

- Store 32,212 robot frames
- Preserve the original robot trajectory on its time axis
- Keep raw state and derived metrics together in JSON
- Simplify the schema with a single TAG table
- Analyze time ranges quickly with JSON path rollups
- Connect real-time queries for a frame and its surrounding window to the UI
- Explore replay, event detection, and anomaly visualization for Physical AI data
