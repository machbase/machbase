LiDAR のポイントデータと距離データをタグおよび時系列データとして保存し、産業安全や物流の監視に向けた空間変化の可視化につなげます。

{{< icon "github" >}} https://github.com/machbase/neo-lidar-demo
<p/>

{{< youtube 41Z2cteWlEE >}}

Machbase Neo に保存した KITTI LiDAR データを使い、3D ポイントクラウドをリアルタイムに再生するデモです。

**主な機能**

- 3D ポイントクラウドの再生
- タイムライン再生
- LOD の調整
- 車両の位置と姿勢の表示
- ミニマップ
- 複数のポイントクラウド表示色

Binary Point API とレンダリングの最適化により、再生性能をさらに向上させています。
