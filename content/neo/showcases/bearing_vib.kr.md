Machbase Neo에 저장된 진동 데이터에서 베어링 결함 주파수를 찾아 설비 상태를 판단하고, 실시간 모니터링부터 상세 분석과 리포트 생성까지 살펴봅니다.

{{< icon "github" >}} https://github.com/machbase/neo-pkg-bearing-analytics
<p/>

{{< youtube 3gu6nw4IXik >}}

핵심 포인트

- API 토큰 로그인과 설비 설정
- NASA 공개 베어링 수명시험 데이터를 실시간으로 재생
- 여러 설비의 진동 추이와 상태 등급을 한 화면에서 모니터링
- 베어링 결함 주파수를 확인하는 상세 주파수 분석
- 각 상태 등급의 판정 근거 확인
- HTML 리포트 생성 및 인쇄·PDF 저장
※ 공개 시험 데이터로 검증한 패키지이며, 실제 현장 설비 데이터로는 아직 검증 전입니다.
