約1時間52分にわたり1秒間隔で記録した車両の6軸 IMU データ（3軸加速度計と3軸ジャイロスコープ、47,096件）を AI が分析し、運転行動を評価するレポートテンプレートです。

**分析パイプライン**

- イベント検出：急加速（AccX が上限を超過）、急ブレーキ（AccX が下限を下回る）、急旋回（GyroZ と AccY がしきい値を超過）の3種類を検出します。平均±2σに基づく適応型しきい値を使い、運転者ごとの異常な瞬間を統計的に捉えます。
- 安全スコア：イベント頻度、危険運転の割合、強度を組み合わせて0～100点で評価し、Safe／Moderate／Risky／Dangerous の4段階に分類します。
- 3軸ベクトルの可視化：タグごとの1秒解像度の生波形と、分単位でロールアップした3軸オーバーレイを表示します。凡例から系列の表示を切り替えられます。
- イベントタイムライン：AccX 波形に急加速（▲）・急ブレーキ（▼）・急旋回（◆）のマーカーを重ねます。イベントが多い場合は最大200件をサンプリングして過負荷を防ぎます。
- イベント集計テーブル：ロールアップのバケット単位でイベント種別ごとの件数と割合を集計し、最も集中した時間帯を特定します。
- Class ラベルによる検証：ラベル0/1/2の時間分布と平均値を用い、教師あり学習の観点から実績と予測を比較します。
- LLM による詳細レポート：安全スコア、加速度パターン、旋回安定性、運転者ごとの評価分布を分析し、根拠・実行内容・期待効果を含む8つの提案と総合診断を生成します。

**操作**

スクロールで拡大・縮小、ドラッグで移動、ダブルクリックでリセットできます。3軸チャートの凡例で系列を切り替え、イベントマーカーの詳細なツールチップを確認できます。

**概要**

IMU 生波形 → 平均±2σに基づく適応型しきい値でイベント検出 → 4段階の安全スコア → 3軸ベクトル可視化 → イベントと波形のタイムライン → LLM による自動診断
