Neo Web과 OPC UA Client 패키지에서 Data Viewer를 열고, 시계열 차트로 데이터를 탐색한 뒤 Tag Analyzer에서 이어서 분석하는 방법을 소개합니다.

이 가이드에서는 Data Viewer를 여는 두 가지 방법을 소개합니다.

먼저 Neo Web에서 Data Viewer를 직접 여는 방법을 살펴봅니다. 이어서 OPC UA Client 패키지의 수집 작업과 연결된 Data Viewer를 여는 방법을 확인합니다.


Data Viewer에서 조회할 태그를 선택하면 결과가 표와 차트로 표시됩니다. 이를 통해 특정 시점의 값과 시간에 따른 데이터 변화를 함께 확인할 수 있습니다.


시계열 차트에서 조회 구간을 이동하거나 원하는 범위를 확대해 데이터 흐름을 살펴볼 수 있습니다. 여러 태그를 선택하면 한 화면에서 변화를 비교해 설비 상태와 데이터 간의 관계를 확인할 수 있습니다.


추가 분석이 필요하면 Data Viewer에서 선택한 태그와 조회 조건을 Tag Analyzer로 전달할 수 있습니다. 같은 조건을 다시 입력할 필요 없이 선택한 데이터를 바탕으로 상세 분석을 이어갈 수 있습니다.


이 영상에서는 Neo Web과 OPC UA Client 패키지에서 Data Viewer를 여는 방법부터 데이터 조회, 차트 탐색, Tag Analyzer 연계까지의 전체 흐름을 확인할 수 있습니다.
