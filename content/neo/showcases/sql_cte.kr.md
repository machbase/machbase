Machbase Neo 8.7에 추가된 SQL 확장 기능(Multi Database, CTE, ARRAY 타입, BINARY 리터럴)을 웹 SQL 에디터에서 직접 실행해 봅니다.

{{< youtube 0V-sWLzHpog >}}

이 영상에서는 수처리장 펌프 설비 데이터를 사용해 Machbase Neo 8.7의 네 가지 SQL 확장 기능을 웹 SQL 에디터에서 직접 실행합니다.


먼저 Multi Database 기능을 살펴봅니다. 한 서버에 여러 데이터베이스를 두고, 다른 데이터베이스의 테이블을 `데이터베이스.소유자.테이블` 형식으로 참조합니다. 시계열 센서 데이터가 있는 기본 데이터베이스와 설비 마스터가 있는 운영 데이터베이스를 한 쿼리로 조인해 랙별 평균 온도와 담당 팀을 함께 조회합니다.


다음은 CTE입니다. `WITH` 절을 사용해 쿼리를 단계별로 구성하고, 여러 CTE를 연결해 앞 단계의 결과를 다시 필터링합니다. 이어서 `INSERT ... WITH ... SELECT`로 CTE 결과를 다른 데이터베이스의 요약 테이블에 저장하고, 저장된 행 수를 조회합니다.


마지막으로 ARRAY 타입과 BINARY 리터럴을 살펴봅니다. `DOUBLE[4]` 컬럼에 네 채널의 파형을 한 행으로 저장하고, 인덱스를 사용해 배열 원소를 조회합니다. 선언한 크기와 다른 배열 입력이 거부되는 것도 확인합니다. BINARY 리터럴은 16진수 `X'0A0B0C0D'`, 2진수 `B'00001010'`, 8진수 `O'012'`로 입력해 저장된 값과 바이트 수를 확인합니다.


애플리케이션에서 데이터를 여러 번 나눠 가져와 조합하지 않아도 됩니다. 데이터베이스 간 조인과 단계별 쿼리, 배열 및 바이너리 값 처리를 SQL 문장으로 수행하는 방법을 확인할 수 있습니다.
