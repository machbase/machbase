Machbase Neo에 기본 제공되는 운영 지표 대시보드(NEO STATZ)를 사용해 서버 상태를 수집하고 확인하는 방법을 소개합니다.

{{< youtube CYw1bhzrwSQ >}}

이 가이드에서는 Machbase Neo에 기본 제공되는 운영 지표 대시보드(NEO STATZ)를 사용해 서버가 스스로 상태를 수집하고 표시하는 과정을 살펴봅니다.

REFERENCE 패널에서 대시보드를 열면 CPU·메모리, 네트워크 연결, 커넥션 풀, APPEND 처리량, 롤업 지연, 쿼리 실행, HTTP 응답 등 15개 패널을 한 화면에서 확인할 수 있습니다.

수집한 지표는 Machbase 데이터베이스의 `NEOSTATZ` 테이블에 60초 간격으로 저장됩니다. SQL 에디터에서 직접 조회해 대시보드의 값과 데이터 저장 주기를 확인할 수 있습니다.

별도의 모니터링 스택이나 지표 수집기를 설치하지 않아도, Machbase Neo를 설치한 직후부터 웹 화면에서 서버 상태를 확인할 수 있습니다.
