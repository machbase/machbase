설비 진동 테이블과 "진동 분석 리포트 만들어줘"라는 요청만으로 AI가 시각화, 심층 진단, 권고 사항을 포함한 HTML 리포트를 생성합니다.

{{< youtube fVrC9ji5Q5M >}}

Machbase Neo 시계열 데이터베이스에 저장된 진동 가속도 원시 데이터(C1/C2 채널, 25.6 kHz, 1,000만 건)를 AI가 분석해 베어링 상태를 진단하는 리포트 템플릿입니다.

**분석 파이프라인**

- 시간 영역 분석: RMS(에너지), P2P(진폭), Crest Factor(충격성), 평균(DC 오프셋)을 초 단위로 롤업해 네 가지 지표를 계산합니다.
- 주파수 영역 분석: 0.2 Hz 해상도의 FFT(최대 12.8 kHz, 4,096개 대역)로 회전 고조파와 베어링 결함 등의 결함 주파수를 찾을 근거를 제공합니다.
- 심각도 판정: ISO 10816-3 기준을 재구성한 기준으로 Good/Warning/Danger/Critical의 4단계를 자동 판정하고 판단 근거(deciders)를 제공합니다.
- 변화율(Trend Ratio) 분석: 초반과 후반의 RMS 변화를 비교해 조기 경보를 제공합니다.
- LLM 심층 리포트: 현황 요약, 스펙트럼 해석, 충격 분석, 근본 원인 추정, ISO 평가, 결함 모드 진단을 서술형으로 작성하고 즉시·단기·중장기 조치 사항을 권고합니다.


**인터랙션**

스크롤 확대·축소, 드래그 이동, 더블클릭 초기화, 밀리초 단위 상세 툴팁을 지원합니다.


**한 줄 요약**

원시 파형 → 시간 영역 4개 지표 → 주파수 영역 FFT → ISO 10816 기반 심각도 판정 → LLM 자동 진단서 생성
