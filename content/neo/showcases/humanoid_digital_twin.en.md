This demo visualizes humanoid robot data with Machbase Neo.

**Highlights**

- Store Humanoid Everyday / OpenHE Motion data
- Replay robot motion in real time with a sensor timeline
- Query and analyze high-speed time-series data

**Demo features**

- Replay Unitree G1 motion in 3D
- Visualize joint, IMU, odometry, and hand-pressure sensor data
- Display RGB, depth, and LiDAR status
- Explore by episode and task
- Retrieve frames with Live Query
- Choose from multiple camera viewpoints
- Download sensor data for a selected episode and copy its query URL

Analyze robot motion and sensor data on one timeline to explore how Machbase Neo can support Physical AI data workflows.
