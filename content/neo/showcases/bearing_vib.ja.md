Machbase Neo に保存した振動データからベアリングの故障周波数を見つけて設備の状態を判断し、リアルタイム監視から詳細分析、レポート作成までを紹介します。

{{< icon "github" >}} https://github.com/machbase/neo-pkg-bearing-analytics
<p/>

{{< youtube 3gu6nw4IXik >}}

**主なポイント**

- API トークンでログインして設備を設定
- NASA の公開ベアリング寿命試験データをリアルタイムで再生
- 複数設備の振動トレンドと状態ランクを1画面で監視
- ベアリングの故障周波数を確認する詳細な周波数分析
- 各状態ランクの判定根拠を確認
- HTML レポートを作成し、印刷または PDF として保存

公開試験データで検証済みのパッケージです。実際の現場設備のデータでは、まだ検証されていません。
