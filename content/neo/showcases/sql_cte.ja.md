Machbase Neo 8.7 で追加された Multi Database、CTE、ARRAY 型、BINARY リテラルを Web SQL エディターで実行します。

{{< youtube 0V-sWLzHpog >}}

この動画では、浄水場のポンプ設備データを使い、Machbase Neo 8.7 の4つの SQL 拡張機能を紹介します。

まず Multi Database です。1台のサーバーに複数のデータベースを配置でき、別のデータベースのテーブルは `database.owner.table` の形式で参照できます。デフォルトデータベースの時系列センサーデータと、運用データベースの設備マスターデータを1つのクエリで結合し、ラックごとの平均温度と担当チームを並べて表示します。

次に CTE です。`WITH` 句で中間結果に名前を付け、クエリを段階的に組み立てます。複数の CTE を連結し、後続の CTE で前の結果をさらに絞り込む方法を実行します。続いて `INSERT ... WITH ... SELECT` を使い、CTE の結果を別データベースの集計テーブルに保存して、挿入された行数を確認します。

最後に ARRAY 型と BINARY リテラルです。`DOUBLE[4]` 列に4チャンネルの波形を1行で格納し、インデックスで各要素を取得します。宣言したサイズと異なる配列が拒否されることも確認します。さらに、16進数 `X'0A0B0C0D'`、2進数 `B'00001010'`、8進数 `O'012'` のリテラルを挿入し、保存値とバイト数を確認します。

アプリケーションからデータを何度も取得して組み立てることなく、データベースをまたぐ結合、段階的なクエリ、配列やバイナリ値の処理を SQL で行う方法を紹介します。
