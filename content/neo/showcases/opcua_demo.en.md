This guide demonstrates the full workflow for collecting data from Kepware with the Machbase Neo OPC UA Client. First, register the OPC UA server endpoint and security settings. Then create and apply certificates for secure communication.

After connecting to the OPC UA server, browse its node structure and select the tags to collect. Register the selected tags as a collection job, and Machbase stores their values at regular intervals.

The video shows how to connect to an OPC UA server, manage certificates, and collect the equipment data you need from the web interface without developing a separate collection program.
