Explore how to find bearing fault frequencies in vibration data stored in Machbase Neo and assess equipment condition, from real-time monitoring to in-depth analysis and report generation.

{{< icon "github" >}} https://github.com/machbase/neo-pkg-bearing-analytics
<p/>

{{< youtube 3gu6nw4IXik >}}

**Highlights**

- Sign in with an API token and configure equipment
- Replay public NASA bearing run-to-failure test data in real time
- Monitor vibration trends and condition grades for multiple machines on one screen
- Perform detailed frequency analysis to identify bearing fault frequencies
- Review the rationale behind each condition grade
- Generate HTML reports and print or save them as PDF

This package has been validated with public test data, but has not yet been validated with data from equipment in actual field operations.
