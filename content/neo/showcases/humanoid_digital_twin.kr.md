휴머노이드의 관절·자세·상태 데이터를 실시간으로 수집하고 Neo 대시보드에서 동작 이상을 확인하는 데모입니다.

{{< icon "github" >}} https://github.com/machbase/neo-humanoid-demo
<p/>

{{< youtube OEYVL7ysXo4 >}}

Machbase Neo를 기반으로 휴머노이드 로봇 데이터를 시각화하는 데모입니다.


**핵심 포인트**

- Humanoid Everyday / OpenHE Motion 데이터 저장
- 실시간 로봇 동작 재생과 센서 타임라인
- 고속 시계열 데이터 조회 및 분석


**데모 주요 기능**

- Unitree G1의 3D 동작 재생
- 관절, IMU, 오도메트리, 손 압력 센서 시각화
- RGB / Depth / LiDAR 상태 표시
- Episode / Task 단위 탐색
- Live Query 기반 Frame 조회
- 다양한 카메라 Viewpoint 지원
- 선택한 Episode의 센서 데이터 다운로드 및 쿼리 URL 복사


로봇 동작과 센서 데이터를 하나의 타임라인에서 분석하며, Machbase Neo를 활용한 Physical AI 데이터 활용 방식을 확인할 수 있습니다.
