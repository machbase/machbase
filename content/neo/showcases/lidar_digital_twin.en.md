Store LiDAR point and range data as tags and time series, then visualize spatial changes for industrial safety and logistics monitoring.

{{< youtube 41Z2cteWlEE >}}

This demo uses KITTI LiDAR data stored in Machbase Neo to replay a 3D point cloud in real time.

**Key features**

- 3D point-cloud replay
- Timeline playback
- LOD adjustment
- Vehicle position and orientation display
- Mini-map
- Multiple point-cloud color modes

Binary Point API support and rendering optimizations have further improved playback performance.
