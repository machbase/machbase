## Overview
The dashboard visualizes data stored in Machbase as charts.  
You can combine several chart panels into one screen and freely adjust the size and position of each panel. It also refreshes the charts automatically at an interval you choose.

{{< media slug="neo-dashboard/statz-board" width="600" >}}

### Starting Dashboard
Click the "DASHBOARD" card on the Machbase Neo home screen to create a new dashboard.

{{< media slug="neo-dashboard/home-new" width="600" >}}

Selecting a saved dashboard file (`*.dsh`) in the "EXPLORER" on the left opens it for viewing or editing.  
A saved dashboard can also be shared as a view-only link. (See "Dashboard Controls".)
