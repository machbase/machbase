# 日本語マニュアル — 独立レビュー

**状態: 翻訳内容を承認済み。** 正規文書 588 件すべてに日本語版があります。
内訳は DBMS 8.7 が 242 件、DBMS 8.5 が 119 件、Neo が 213 件、Apps が 1 件、
Fluid が 8 件、開発者向け文書が 5 件です。この報告書は以前の DBMS 限定の承認を更新します。

翻訳と独立レビューを並行して行いました。検収者は他の担当者が作成した文書を確認し、
TQL の翻訳者は自分の TQL 翻訳を承認していません。韓国語・英語の製品原文は保持しています。
両言語の内容が異なる場合は追加情報も日本語版に含め、主原文、比較原文、根拠のある修正を記録しました。

## 根拠と再実行できる検証

- `scripts/japanese_manual_sources.json` に、両言語の原文選択と修正の根拠を記録しています。
- `scripts/japanese_manual_reviews.json` の個別承認は、原文・翻訳文・比較原文の正確なハッシュと、
  検出事項のフィンガープリントに結び付けています。構造や生成物のエラーは引き続き解消が必要です。
- `scripts/japanese_manual_coverage.json` に、全文書の原文・日本語版のハッシュと独立検収者を記録しています。
  自動検出事項がなかったページも含みます。
- [日本語マニュアルの保守](JAPANESE_MANUAL.ja.md) に、原文対照、生成サイト、単体テスト、
  ブラウザー検証を再実行するコマンドがあります。

最終の通常 Hugo ビルドは `--gc --minify --printUnusedTemplates --printI18nWarnings` で成功しました。
生成物の監査では、正規の日本語製品ページ 564 件と、内部リンク・アセット・フラグメント
414,299 件を確認し、エラーはありませんでした。公開ページごとの Markdown 本文と、
DBMS の 242 文書から成る `llms` 全文は、文書化したリンクのローカライズを除き、
現在の日本語ソースと一致します。エイリアスのリダイレクトは別途検証し、正規文書数には含めません。

Python テスト 51 件すべてに合格しました。ブラウザー検証 19 項目にも合格し、ページや検索の
エラーは記録されていません。Neo、DBMS 8.7、DBMS 8.5、Apps の日本語ホームとナビゲーション、
同じ記事の言語切り替え、日本語検索と IME 確定、インデックス読み込み遅延時のクエリ置換・
Escape・フォーカス解除、検索結果なし、クリップボード、テーマ、モバイルの移動と画面幅、

## 内容の検証

本文全体、表の項目と単位、SQL/API 識別子、オプション、デフォルト値、制約、例、期待結果、
見出し、アンカー、ショートコード、リンクを検収しました。サーバーの元のメッセージと、
意味を持つサンプルデータは元の言語を保持しています。DBMS 8.5 のエラー辞書は全 857 項目に
日本語の説明があります。DBMS 8.7 の公開カタログは、原文マニフェスト 1,086 件から既存の
除外 24 件を除いた 1,062 件を保持しています。

ソースに基づく修正には、復元の前提条件、保持期間の単位と削除基準時刻、メタデータ操作、
数値例、UTF-8 の列容量、コマンドフラグ、コネクターの単位、JavaScript の対応範囲、
旧 Tengo の例などがあります。修正と根拠は個別の検収記録に残し、別バージョンの製品仕様へ
一律に適用する変更は行っていません。

隔離した Neo 環境で、一部の SQL、メタデータ、TQL 変換、MQTT メッセージ、UTF-8 の動作を
検証しました。TQL のコンパイル監査は 337 例を対象とし、325 例に成功しました。
SRC のみの断片 9 例には SINK が必要で、8.7 と明記された 3 例は旧版のローカル Neo では
使用できません。すべてのインストール手順や外部データベース用コネクターを実行したという意味では
ありません。検証で既存の本番データベースやクラスタ構成は変更していません。

## 検証状態との対応

この承認は、coverage と review マニフェストに記録したハッシュに適用します。
原文や翻訳を変更した場合は、該当するレビューと生成物を再確認してください。既存の韓国語 i18n
およびテーマの未使用テンプレートの警告は、日本語の内容・UI の検証と区別しています。
コミット、プッシュ、デプロイは、このレビューとは別の作業です。
